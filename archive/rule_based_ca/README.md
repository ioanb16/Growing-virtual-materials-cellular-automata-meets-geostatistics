# Archived: rule-based cellular-automata track

Earlier exploration of an explicit-rule CA (majority / probabilistic-Potts,
boundary modes, nucleation, conservation feedback) used to study how rules
shape morphology (project Goal 2). Superseded for generation by the empirical
Karnaugh-map engine in `pgsca/karnaugh_tools.py`, but kept for reference and
for its findings (proportion drift, weighted-vote homogenization).

Notebooks here import the old top-level module layout and are not expected to
run against the current package without path edits.
